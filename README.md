# EscapeLavaForLoot

Roblox game built with [Rojo](https://rojo.space). Toolchain is pinned in `rokit.toml`.

## Setup

```bash
rokit install      # rojo, wally, blink, stylua, selene, lune
wally install      # Packages/ and ServerPackages/
blink Remotes.blink
rojo serve
```

Open `Game/EscapeLavaForLoot.rbxl` in Studio and connect the Rojo plugin.

## Where things go

| Path | What belongs there |
| --- | --- |
| `Game/EscapeLavaForLoot.rbxl` | The working place file. **Commit it.** The map, lava and anything built in Studio live here. |
| `src/ReplicatedStorage/Assets/` | Studio-made models/UI the client needs. Rojo leaves unknown instances alone. |
| `src/ReplicatedStorage/Client/` | Client-only modules: UI, input, effects, controllers. |
| `src/ReplicatedStorage/Shared/Configs/` | Config **safe for players to read**. |
| `src/ReplicatedStorage/Shared/Types/` | Shared Luau types. |
| `src/ReplicatedStorage/Shared/Util/` | Helpers used by both client and server. |
| `src/ReplicatedStorage/Shared/Networker/Client.luau` | Generated by Blink. Don't edit. |
| `src/ServerScriptService/Configs/` | Server-only config: loot tables, drop rates, rewards. |
| `src/ServerScriptService/Features/` | Server services. |
| `src/ServerScriptService/Util/` | Server-only helpers. |
| `src/ServerScriptService/Networker/Server.luau` | Generated by Blink. Don't edit. |
| `src/ServerScriptService/Runner.server.luau` | The only server Script. Loads services. |
| `src/ServerStorage/` | Server-only models (loot, map pieces). |
| `src/StarterPlayer/StarterPlayerScripts/Client.client.luau` | The only LocalScript. Loads controllers. |
| `src/StarterPlayer/StarterCharacterScripts/` | Scripts cloned into each character. |

## Rules

- **Anything in ReplicatedStorage is readable by exploiters.** Loot tables, drop rates and reward values go in `ServerScriptService/Configs`, never `Shared/Configs`, even if the client wants to show something. Send the client only what it needs over the network.
- **One Script, one LocalScript.** Everything else is a ModuleScript registered in the Runner or Client list, exporting optional `Init()` (no yielding, no calling other services) and `Start()`.
- **Networking goes through Blink.** Edit `Remotes.blink`, then run `blink Remotes.blink`. Never hand-edit the generated files.
- Format with `stylua src`, lint with `selene src`. Generated files and packages are excluded.
